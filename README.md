# 律动 Studio for MyGo Music

以歌词为主体的**电影字幕风**：大字排版、逐词渐显、轻微上移与平滑换句。采用原生文字渲染。

> 需要本项目提供的 **Stage API 1 适配版播放器**。官方 MyGo Music 0.1.22 没有律动扩展接口，单独安装此插件不能替换原版律动页面。这里的 0.1.23 是本项目的自定义构建版本，不代表上游发布。

## 使用

1. 从本项目 Releases 下载 Windows 适配版及 `stage-studio-plugin.zip`。
2. 完全退出原版 MyGo Music（包括托盘进程），运行适配版 `MyGo Music Stage.exe`。原安装包无需卸载。
3. 设置 → 插件 → ＋ → 从本地 ZIP 安装 `stage-studio-plugin.zip`；也可从 GitHub 安装本仓库。
4. 播放音乐，进入 **律动 → 律动效果**，选择 **律动 Studio · 电影字幕**。
5. 选择「流光 / 云阶 / 倾诉」可恢复原内置效果。禁用或卸载插件时也会回退。

适配版沿用原应用名称和数据目录，可继续读取已有歌单与音乐源。首次尝试前建议备份 `%APPDATA%\MyGo Music`。退出适配版后仍可运行原安装目录里的播放器。本项目不会自动覆盖原 EXE。

## 效果与清晰度

- **电影字幕**：暖白大字、深色底、克制的金色细节。
- 逐词渐显与轻微浮动，由当前歌曲的歌词时间驱动。
- 长句平衡为两行，字体宽度由原生引擎测量，保留英文词间空格。
- 换句时上一句淡出上移，新句缓慢进入。
- 字体按最终字号交给原生文字引擎栅格化；不先绘制低清文字贴图再放大，不对前景文字做模糊。
- 原生逻辑像素与 Windows 显示缩放配合；插件没有固定 720p 或 1080p 画布。
- 暂停时静止，拖动进度可重复得到同一画面；系统「减少动态效果」会冻结装饰动画。

歌词由当前音乐源提供。本插件不联网搜索或补全歌词；无歌词时显示歌名与提示。歌曲里的逐词时间如果缺失，效果精度取决于播放器对整行歌词的时间分配。演示视频里的整句时间来自该歌曲的时间轴，逐词时间是句内估算。

## 文件与权限

- `plugin.json`、`index.js`：可独立安装的插件，无需打包或 npm install。
- `stage-api.patch`：基于上游 `1af0d8efd77fdf630c27cfc635f12e9cb089ce10` 的适配补丁。
- `build-host.ps1`：下载指定上游版本、应用补丁、编译 Windows 程序。
- `stage-api.md`：开放接口说明，可据此编写其他律动插件。

插件无网络权限、无进程权限，不读取其他插件的账号或文件。仅在用户选中它为律动渲染器时，本体向它传入当前歌曲名称、时间、邻近歌词和音频频段。绘制计算在工作线程完成，最多 30 次/秒；异常或超时回退内置律动。

本适配版关闭上游自动更新，防止被不包含 Stage API 的官方版本替换。需要升级时，请重新适配并构建。

## 开发

插件测试：`node --test stage.test.js`（Node.js，无第三方 npm 依赖）。

构建本体：安装 Git 与 Go 1.27.3，然后在 PowerShell 执行：

```powershell
./build-host.ps1
```

完整构建还可使用上游的 `go tool mygo build`（需要 Bun）。本仓库脚本直接输出便携 EXE，不修改系统安装目录。

本项目基于 [egoist/mygo-music](https://github.com/egoist/mygo-music)，依照 AGPL-3.0 分发；不是上游官方发行版。发布包不包含歌曲或歌词资源。
